# VEM Hero Demo

This small demo shows a luxury, dark hero section inspired by the VEM brand.

How to view
- Open `hero/index.html` in your browser. The demo uses the Tailwind CDN and Google Fonts, so an internet connection is required.

Notes
- Palette uses the brand navy `#223168` and gold `#B99B5F` from the `brand/README.md`.
- Fonts: `Playfair Display` for display, `Source Sans 3` for body.
- Accessible: respects `prefers-reduced-motion`, includes semantic HTML and focus rings.
